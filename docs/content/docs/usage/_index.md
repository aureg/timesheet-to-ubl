Cette section sert de point d'entrée pour l'utilisation de `ublcli`.

## Parcours recommandé

1. [`Quick Start`](/docs/quick-start) pour une première génération rapide.
2. [`CLI`](/docs/usage/cli) pour la référence complète de la commande `generate`.
3. [`Configuration YAML`](/docs/usage/config-yaml) pour documenter `config.yaml` (clés, valeurs, défauts, exemples).
4. [`TUI`](/docs/usage/µtui) pour le mode interactif.

## Ce que vous trouverez dans ces pages

- **CLI**: options, alias, types, obligations, valeurs par défaut et exemples.
- **Configuration YAML**: structure complète, priorités de résolution, templates, exemples prêts à l'emploi.
- **TUI**: lancement, comportement, et quand préférer la TUI au mode CLI.

Pour les détails techniques internes du code, voir [`Architecture`](/docs/architecture).
